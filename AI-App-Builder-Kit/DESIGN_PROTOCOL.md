# Design Protocol — Core Layer v0.1

特定の「見た目」を強制せず、意図、階層、可読性、一貫性、刺激量、検証を設計するためのCoreです。色、素材、かわいさ、硬さ、アナログ感等の方向性はPersonalizationまたはPresetで決めます。

## 1. 実装前にDesign Intentを作る

大きなUI変更では、次を短く定義します。

- **Purpose**：この画面で達成すること
- **Audience / Context**：誰が、どこで、どの端末で使うか
- **Emotion**：どう感じてほしいか
- **Character**：印象を表す3〜5語
- **Hierarchy**：Hero / Supporting / Background
- **Density / Sensory budget**：情報量、動き、音、通知の上限
- **Shape / Color / Typography / Motion / Sound**：方向性と役割
- **Avoid**：避けたい表現

デザインは実装後に色や角丸を足す作業ではありません。

## 2. 参考事例を分析する

重要画面では、可能なら3〜8件の参考例を調べます。コピーではなく、配色、余白、密度、視線誘導、文字階層、形、動き、音がなぜ機能しているかを分析します。ライセンスやブランド表現をそのまま転用しません。

## 3. 最初の案を完成版としない

重要な画面では、可能なら2〜3方向のラフを比較します。初回実装後にも、機能QAとは別にVisual / Sensory QAを行い、少なくとも一度は削る・整える・比較する機会を設けます。

## 4. 階層、余白、一貫性

- 1画面の主役を明確にする。
- 全要素を同じ強さで見せない。
- 関係が近い要素は近く、異なる要素は離す。
- 区切りを枠線やカードだけに頼らない。
- 色がなくても大まかな階層が分かるようにする。
- Color、Spacing、Type、Radius、Motion等を少数のトークンで管理する。
- アイコン、イラスト、UIの線、形、影、質感を一貫させる。

白背景、角丸カード、薄い枠、青い主ボタン等を無意識の既定値にしません。採用する場合は役割を説明できるようにします。

## 5. 刺激予算を持つ

- 常時動く装飾を増やしすぎない。
- 強い色、音、通知、バッジが注意を奪い合わないようにする。
- 情報が多い場合は段階表示を検討する。
- 自動再生や突然の大音量を避ける。
- 音や動きは主要情報の唯一の手段にしない。
- Reduce Motion、ミュート、代替表示を必要に応じて用意する。

「表示できるから表示する」「動かせるから動かす」を理由にしません。

## 6. Typography / Motion / Sound / Assets

- 本文の可読性、行間、サイズ、ウェイトを優先する。
- カスタムフォントは、ライセンス、容量、文字範囲、fallback、表示遅延を確認する。
- Motionは状態変化や関係を伝える役割を持たせ、短く、停止・軽減可能にする。
- Soundは任意の補助とし、無音でも主要操作を理解できるようにする。
- 画像、音、フォント、アイコンは利用・再配布条件を記録する。
- アセット読み込み失敗でも主要機能と可読性を守る。

具体的な「柔らかい音」「硬質な動き」等はCoreではなくPresetで選びます。

## 7. QAを分ける

### Functional QA

目的の操作が完了でき、状態と結果が正しいか。

### Accessibility QA

コントラスト、色以外の手掛かり、キーボード、フォーカス、読み上げ名、拡大、Reduce Motion、エラー回復等を確認します。

### Visual QA

主役、視線、余白、整列、文字階層、密度、色数、カード・影の必要性、世界観の一貫性を確認します。

### Sensory QA

5分程度使ったとき、動き、色、音、情報量で不必要に疲れないかを確認します。これは目安であり、実際の対象者テストを置き換えません。

### Performance / Fallback QA

低速回線、狭い画面、アセット未読込、音声非対応、外部サービス失敗でも、主要機能が成立するかを確認します。

## 8. 主観的な違和感を分解する

「雑然としている」「硬い」「幼く見える」「疲れる」等の反応は、比率、余白、整列、密度、文字、色、動き、音、情報階層へ分解します。主観を無視せず、同時にアクセシビリティと機能性を守れる解決を探します。

美的方向の最終判断は利用者にあります。Coreは特定の美意識を強制せず、その意図を一貫して実現・検証する方法を提供します。
